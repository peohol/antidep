# Roadmap

Neste sammenhengende leveranse er **fulltekstbibliotek + reell agentkjede + én lesbar klinikerflate med sluttkontroll**.

Den skal gi privat PDF-opplasting, serverkontrollert filidentitet og publikasjonstilhørighet, lesbarhet/tabellkontroll, varig idempotent jobbtilstand, reelle separate modellroller, synlig kildedekning og en kandidatbundet sluttkontroll i klinikerens renderer. Først deretter åpnes ny publiserings-API.
